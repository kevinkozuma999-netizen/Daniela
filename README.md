# Landing Page — Dra. Daniela De Luca | Verão

Landing page estática pronta para GitHub + Vercel.

## Publicar
1. Crie um repositório novo no GitHub.
2. Envie **o conteúdo desta pasta** (index.html, styles.css, script.js e a pasta assets) para a raiz do repositório.
3. Na Vercel, clique em **Add New > Project** e importe o repositório.
4. Em Framework Preset, escolha **Other** (normalmente a Vercel detecta automaticamente).
5. Não é necessário Build Command. Clique em **Deploy**.

## Editar
- Textos: `index.html`
- Cores/layout: `styles.css`
- Imagens: pasta `assets/`
